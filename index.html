FAQ

Questions clients ask before we start

The things worth knowing up front. Anything else, just ask me directly.

Where are your clients based?

I'm in Jaipur, Rajasthan, and every project runs remotely — so whether you're in Delhi, Mumbai, Bengaluru, Hyderabad, Pune, Chennai, Kolkata, Ahmedabad or a town nobody outside it has heard of, the way we work is identical: email, WhatsApp and video calls, with progress shared as I go. I take international projects on the same basis. I'm on IST (UTC+5:30), which overlaps comfortably with Europe, the Middle East and Asia-Pacific; for US time zones I'll shift calls to suit you and keep written updates flowing either way.

How much does a website cost in India?

Honestly, it depends on what it has to do. A straightforward business website starts at ₹7,000; a custom web application with logins, dashboards and integrations starts at ₹20,000 and goes up with scope. Redesign and backend work I quote on scope rather than advertise at a number. The service cards list the starting points, and this cost breakdown explains what moves the number up or down — including the yearly costs after launch.

Should I get a custom site or use a template?

A template is genuinely the right answer when you need a presence online this week and the content is simple — I'd rather tell you that than sell you something bigger. Custom earns its cost when you need something a template can't do: logins, a dashboard, an integration, or a specific flow your business actually runs on. React vs WordPress works through that decision properly, including when the answer is that you don't need me.

How long does a project take?

I don't quote a timeline before I understand the scope. In the planning stage you get a feature list, the technology I'll use and a fixed timeline in writing, so the delivery date is agreed before any code is written.

Which technologies do you build with?

React.js on the front end, Node.js and Express with MongoDB on the back end — the MERN stack — plus REST APIs, JWT authentication and AI APIs where a project calls for them. The full tech stack lists everything I use day to day.

Can you work on an existing website?

Yes — it's a large part of what I do. Performance optimisation, responsive fixes, UI clean-ups and new features on a site that already exists. Pick Website Redesign or Website Maintenance in the enquiry form.

How do we work together if we never meet?

The same way most software gets built. We agree the scope in writing, I build in stages and share progress as I go, and you give feedback while changes are still cheap. You see the work before it ships, not after. If you're weighing up developers, this guide to choosing a freelance web developer lists the questions worth asking me — and everyone else.

What happens after the site goes live?

I deploy the project, hand over the code and walk you through it, and I'm available after launch if something needs changing or you want to add to it. You own the code either way.
